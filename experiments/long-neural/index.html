Лаборатория нейронного бота

Это локальный учебный стенд, не игра на портале. У него нет доступа к комнатам, аккаунтам или защищённому генератору бросков. Значения учебных кубиков задаёте вы.

1. Загрузите JSON-модель

Модель не загружена. Выбор хода отключён.

Загрузка подтверждает только формат весов, не силу игры. Случайная инициализация — необученная сеть. Даже обученная модель требует независимых матчей против разных соперников; оценка сети пока не является доказанной вероятностью победы. Манифест учебного файла — данные его автора, не подтверждённое происхождение модели.

2. Задайте учебный бросок

Первыми ходят белые. Броски здесь не случайные.

Загрузите модель, затем выберите ход.

Модель видит текущую позицию; движок правил проверяет все действия. После применения хода можно указать следующий учебный бросок для другой стороны. Поиск ограничен: поле «покрытие поиска» показывает число рассмотренных вариантов и усечение. Никакие сведения не отправляются по сети.
